# Learning Library Guide

The Learning Library is a reference area that does not change the active class, assignment, or Full Studio dataset.

## Glossary

Use the search field for a term or idea, then optionally narrow the result by topic group. The page displays one selected entry at a time:

- Definition
- Why the term matters
- Formula or notation, when relevant
- Related terms

A collapsed matching-term table is available for broader browsing without stacking every definition on the page.

## Model Explorer

Search by model name, family, or task. Each model entry contains:

- How the model works
- Input and output
- Appropriate use
- Strengths and limitations
- Relevant parameters and what they control
- Recommended evaluation approach

The explanations follow the names and controls used in the analytical pages.

## Course Map

The Course Map provides a compact Week 1–16 sequence. It is intended for orientation and review rather than as a replacement for Today’s Lab.
